# practica-Dead-Mans-Switch-mvp

MVP de la práctica grupal Dead Man's Switch de Comunidad UX/UI.

Dead Man's Switch es una app de prueba de vida: quien sale o vive sola confirma con un toque que está bien y, si no lo hace a tiempo, la app avisa por correo a sus contactos de confianza.

Las instrucciones para instalar y trabajar en el proyecto se suman aquí cuando esté el núcleo.
